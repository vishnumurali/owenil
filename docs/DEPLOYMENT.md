# Deploying Owenil to GitHub Pages

**Live URL:** https://vishnumurali.github.io/owenil/

Owenil is a static single-page app. GitHub Pages hosts it for free from the public repository `vishnumurali/owenil`. Supabase holds all data, authentication and scheduled jobs, so there is no server to run.

## How a deploy happens

Every push to `main` runs [`.github/workflows/deploy.yml`](../.github/workflows/deploy.yml):

1. `npm ci`
2. `npm test` (unit, SQL and component tests; a failure stops the deploy)
3. `npm run build` with the base path `/<repository name>/`
4. Upload `dist/` and publish it to Pages

You can also start it by hand from **Actions → Deploy to GitHub Pages → Run workflow**.

## Build-time configuration

The browser bundle contains only public settings. In the repository, go to **Settings → Secrets and variables → Actions → Variables** and set:

| Variable | Value |
|---|---|
| `VITE_SUPABASE_URL` | `https://<ref>.supabase.co` |
| `VITE_SUPABASE_PUBLISHABLE_KEY` | `sb_publishable_…`. It's public by design and safe because of Row Level Security. |
| `VITE_ENABLE_DEV_TOOLS` | `true` while testing (shows the "Enable Plus for testing" switch to testers). Use `false` or remove it for production. |

Never add the Supabase **secret key**, **access token** or **database password** to the repository, its variables or its secrets. The site doesn't need them.

For local builds, the same values come from `.env.local` (see `.env.example`).

## Supabase settings that depend on the URL

**Authentication → URL Configuration**
- **Site URL:** `https://vishnumurali.github.io/owenil/`
- **Redirect URLs:** `https://vishnumurali.github.io/owenil/**` and `http://localhost:5173/owenil/**`

`npm run supabase:provision -- --auth-urls` sets both through the Management API.

## How static hosting is handled

GitHub Pages serves files only. It can't run code or set response headers, so:

| Need | How it's handled |
|---|---|
| Deep links such as `/owenil/groups/<id>` | The build copies `index.html` to `404.html`, so Pages answers unknown paths with the app, which then routes on the client. The HTTP status for those first loads is 404, which browsers ignore. |
| Content Security Policy | A `<meta http-equiv="Content-Security-Policy">` tag is added to production builds (see `vite.config.ts`). It allows scripts only from the site itself and connections only to Supabase. |
| Clickjacking protection | `frame-ancestors` doesn't work in a meta tag, so `public/theme-init.js` breaks out of, or blanks, any page that frames the app. |
| Referrer policy | `<meta name="referrer" content="strict-origin-when-cross-origin">` |
| Caching | Pages caches every file for 10 minutes. Asset file names are content-hashed, so a new deploy is picked up within that time. |

## Check a deployment

```bash
curl -sI https://vishnumurali.github.io/owenil/ | head -1               # 200
curl -s  https://vishnumurali.github.io/owenil/ | grep -c Content-Security-Policy  # 1
curl -s  https://vishnumurali.github.io/owenil/groups/abc | grep -c 'id="root"'    # 1 (SPA fallback)
E2E_BASE_URL=https://vishnumurali.github.io/owenil/ npm run test:e2e
```

## Rolling back

- Revert the bad commit (`git revert <sha>`) and push. The workflow redeploys the previous code.
- Or re-run an earlier successful **Deploy to GitHub Pages** run from the Actions tab.
- To take the site offline, go to **Settings → Pages** and unpublish it, or disable the workflow.

## Using a custom domain later

1. Add the domain under **Settings → Pages → Custom domain** and create the DNS record GitHub shows.
2. For a domain root or subdomain, set the repository variable `VITE_BASE_PATH=/` and change the build step to use it.
3. Add the new URL to the Supabase **Site URL** and **Redirect URLs**, and to the Google OAuth client's JavaScript origins if Google sign-in is enabled.

## Server-side scheduling

Recurring expenses are generated by `pg_cron` inside Supabase (job `owenil-recurring`, hourly). Nothing runs on GitHub, and no browser needs to be open. To run it manually: `npm run recurring:run`, or **Recurring → Run due now** in the app.
